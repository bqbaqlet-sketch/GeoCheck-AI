# Входные данные

GeoLab-01 — синтетическая скважина, 801 отсчёт от 2100 до 2300 м с шагом 0,25 м. Каналы GR, RHOB, NPHI, DT и RES моделируются совместно с фиксированным seed. В labels.json указаны точные границы искусственных изменений. Для воспроизведения выполните `.\.venv\Scripts\python.exe backend/app/demo.py` из корневой папки.

CSV поддерживает разделители запятая, точка с запятой и табуляция, кодировки UTF-8 и Windows-1251. Колонка глубины именуется DEPTH, DEPT, MD или ГЛУБИНА. Пример заголовка — `DEPTH [ft],GR [API],RHOB [g/cm3]`. Неизвестные единицы отображаются знаком вопроса. Разрешены пустые значения каналов. Глубина обязательна и уникальна, исходный порядок сохраняется в оригинальном файле, рабочие массивы сортируются по глубине. Чисто текстовые поля исключаются из числовых треков.

LAS каротажа читается библиотекой lasio. Проверен импорт LAS 2 с NULL, футами и названием скважины. [Поддерживаемые версии LAS](https://lasio.readthedocs.io/en/latest/).

## FORCE 2020

Если у команды уже есть разрешённая копия таблицы FORCE 2020, выделите один WELL и числовые каналы. Пример для стандартных названий полей, с заменой WELL-NAME на значение из вашей таблицы:

```powershell
.\.venv\Scripts\python.exe backend/prepare_force.py "D:\datasets\train.csv" "WELL-NAME" "well.csv" --curves GR RHOB NPHI --depth DEPTH_MD
```

Параметр --sep задаёт разделитель. Скрипт записывает новый файл и сохраняет реальные значения глубины. Уточните единицы по документации конкретной поставки и подпишите заголовки перед импортом. FORCE в поставку прототипа не входит. Для оценки по нескольким скважинам потребуется разбиение по идентификаторам WELL.

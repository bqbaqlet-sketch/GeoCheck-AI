# Контроль качества и интерпретация

Вход модуля — исходные кривые и монотонно возрастающая последовательность глубин. Параметры проходят Pydantic-валидацию. Вычислительный сервис не зависит от HTTP, SQLite или React.

| Метод | Как формируется предупреждение |
|---|---|
| Пропуски | Поиск NaN по каждому выбранному каналу. Последовательные отсутствующие отсчёты объединяются. |
| Физические правила | Неположительная плотность RHOB, интервальное время DT или удельное сопротивление RES при распознанных единицах. Конкретные сочетания перечислены в ml.py. Для остальных сочетаний отчёт фиксирует пропуск правила. |
| Выброс | Расстояние от медианы выше порога, умноженного на 1,4826 × MAD. Для нулевого MAD используется численный нижний предел. |
| Скачок | Тот же критерий для изменений значения на единицу глубины. Предупреждение привязывается к глубине второго отсчёта пары. |
| Isolation Forest | Медианная импутация, StandardScaler и лес со случайным зерном 42. Строки без всех выбранных измерений исключаются. При менее чем восьми пригодных строках метод пропускается. В интерактивной проверке фон оценивается на выбранной скважине. |

Выход хранит границы интервалов, канал, метод, объяснение и число отсчётов. Значение IF score равно минус score_samples, больший результат соответствует большей аномальности. Порог задаёт contamination. Score не является вероятностью ошибки. Для CSV служебные числовые коды пропусков нужно интерпретировать по описанию поставщика. Для LAS используется объявленный NULL. [Документация Isolation Forest](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.IsolationForest.html).

## Независимая оценка

Команда `.\.venv\Scripts\python.exe backend/evaluate.py` создаёт чистую обучающую скважину с seed 117 и отдельную тестовую с seed 2026. Медианы, масштабы, деревья и порог определяются исключительно по обучающей скважине. В тестовой скважине 801 строка и пять искусственных интервалов, всего 49 положительных строк. Оценка проводится по глубинным отсчётам для Isolation Forest отдельно. Результаты интерактивного анализа могут отличаться из-за другого фона обучения.

| TP | FP | FN | Precision | Recall | F1 |
|---:|---:|---:|---:|---:|---:|
| 20 | 24 | 29 | 0,455 | 0,408 | 0,430 |

Медианная импутация способна скрыть пропуски от Isolation Forest. Для пропусков предусмотрена отдельная проверка. Резкая геологическая граница также может выглядеть как выброс. Обе синтетические скважины построены одним генератором, задано всего пять типов вмешательства и один тестовый seed. Перенос метрик на промысловые данные потребует независимо размеченных скважин, разделения по скважинам и проверки экспертом. Интервалы методов могут пересекаться. Участки с искусственно внесёнными изменениями перечислены отдельно в data/demo/labels.json.
